# Блог: как устроена система контроля позиции

Серия статей о том, что делает система, для кого и как она устроена. Каждая
статья написана для двух читателей: финансист учится раскладывать работу
управляющей компании на сценарии и требования, инженер — строить похожие
системы.

Статьи пишутся по ходу разработки и описывают то, что уже сделано и
проверено. Принятые, но ещё не реализованные решения помечены отдельно.

У каждой статьи есть HTML-версия с тем же именем — самодостаточная страница
без внешних ресурсов. Источник — markdown: после правки статьи выполните
`make blog`, а CI проверит, что HTML не отстал (`make blog-check`).
