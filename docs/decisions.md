# Решения по предметной области

Журнал ответов пользователя на уточняющие вопросы. Номер — номер вопроса
в обсуждении. При изменении решения старая запись не удаляется, а
дополняется новой с датой.

## Модель данных (2026-10-24)

| № | Решение |
|---|---|
| 1 | ПИФ — головной compound. СЧА и комиссии считаются на уровне фонда. |
| 2 | Compound может входить в несколько compound; physical — тоже. Циклов нет. |
| 3 | Physical относится к одной паре «денежный счёт + счёт депо». |
| 4 | Пока только рубли. Валюты — отдельная доработка в будущем; поле валюты есть в модели. |
| 5 | Денежные операции: выдача и погашение паёв; начисление расходов (уменьшает СЧА); выплата расходов (уменьшает деньги); переводы между портфелями. |
| 6 | Ролл — на каждый календарный день; сделки — по торговому календарю Мосбиржи. |
| 7 | День закрывается после сверки; нужен функционал сверки. Правка в закрытом периоде — только админом с комментарием. |
| 8 | Замещённые снапшоты расчётов хранятся: можно воспроизвести, что система показывала до исправления. |
| 9 | История начинается с инициации фонда (первой выдачи паёв); входящих остатков нет. |
| 32 | У physical ровно один фонд-предок; фонд не входит в другой фонд. |
| 33 | Несколько physical одного фонда могут быть на одной паре счетов; лестница расчётов — по счёту. |
| 34 | Схема срочного рынка пока неизвестна, нужна гибкость: единый счёт — позиции в том же physical; отдельный счёт — в отдельном physical. |
| 35 | Операции уровня фонда проводятся в назначенный казначейский physical. |
| 36 | Ведём количество паёв и расчётную стоимость пая. |
| 37 | Переводы между портфелями — деньги и бумаги, только внутри фонда, с датой исполнения. |
| 38 | Сверяемся с брокером. |
| 39 | Дни закрываются строго подряд; закрывает сопровождение, открывает заново только админ с комментарием; повторное открытие — новая версия снапшотов и новая сверка. |
| 40 | Сверяются только количества бумаг и остатки денег. Наша оценка может отличаться от официальной — это нормально; официальную СЧА не воспроизводим. |
| 41 | Работающих фондов нет — импорт истории не нужен. |

## Процессы и MVP (2026-10-24)

| № | Решение |
|---|---|
| 42 | Операция выдачи или погашения паёв сразу меняет количество паёв и создаёт требование (выдача) или обязательство (погашение). Когда расчёт прошёл, сопровождение отмечает это вручную — тогда меняются деньги. |
| 43 | Вознаграждение начисляется ежедневно от нашей СЧА. При выплате вводится фактическая сумма; разница проводится корректирующим начислением в дату выплаты, обязательство обнуляется. Корректировка видна в журнале и в разложении P&L. |
| 44 | Количество паёв считается в системе по операциям выдачи и погашения. |
| 45 | Бумаги переводятся по средней цене портфеля-отправителя, без финансового результата; одна дата исполнения для обеих сторон. |
| 46 | Парсеры отчётов брокеров — позже. Сейчас нужен только приёмник остатков. |
| 47 | Тип денежного счёта: брокерский или банковский. Остаток банковского счёта сопровождение вводит вручную по выписке. |
| 48 | День закрывается по фонду целиком, после сверки всех счетов фонда. |
| 49 | MVP: облигации с фиксированным купоном, флоатеры, РЕПО, БПИФ. Фьючерсы и OIS — второй этап. |
