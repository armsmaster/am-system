в обсуждении. При изменении решения старая запись не удаляется, а

## Справочник инструментов и расчёты (2026-10-26)

| № | Решение |
|---|---|
| 10 | Поддерживаем амортизацию и колл-опционы эмитента. ОФЗ-ИН (индексация на ИПЦ) не поддерживаем. |
| 11 | Купоны, оферты и амортизации берём из MOEX ISS. Сопровождение может поправить параметры вручную; каждая правка — новая версия инструмента. |
| 13 | Новая версия инструмента действует с даты публикации новых купонов. Расчёты за прошлые дни остаются на старой версии. |
| 25 (справочник) | Загрузить новую бумагу могут и трейдинг, и сопровождение: в интерфейсе вводят код бумаги, система находит её в MOEX ISS и загружает. Править бумагу может только сопровождение — и ежедневная автоматическая синхронизация с MOEX ISS. Роли в сделках и операциях — открытый вопрос 25. |
| 56 | Весь список облигаций биржи не загружаем — только бумаги, которые добавили пользователи. |
| 57 | Торговый календарь ведём в системе; переносы выходных сопровождение заносит раз в год. |
| 58 | Дата расчётов всегда есть в данных сделки. Срок по умолчанию (T+1 для облигаций и паёв, T+0 для размещений и РЕПО) — только подсказка при ручном вводе. |
| 16 | НКД не рассчитываем сами — берём из MOEX ISS. Это позволяет считать стоимость (MV) и результат (P&L) позиций и в реальном времени, и за прошлую дату. Эталонный Excel для НКД не нужен. |
| 15 | Для вменённого кредитного спреда флоатера купон полностью не моделируем. Достаточно: маржи к плавающей ставке, текущих чистой и грязной цен, типа плавающей ставки (сама ставка и признак капитализации), расписания купонов, признака индексации номинала. |
| 59 | Поле, поправленное сопровождением вручную, закрепляется: синхронизация с ISS его не перезаписывает, но показывает расхождение. |
| 60 | ISS публикует НКД на дату расчётов. Для нерасчётных дней НКД интерполируем сами. |
| 61 | Подписки на данные ISS нет — пользуемся только открытой частью. |
| 63 | Версия бумаги хранит только условия выпуска. Номинал на дату в версию не входит: у обычной облигации он следует из начального номинала и графика амортизаций, у облигации с индексируемым номиналом — из ряда «бумага, дата, номинал». Ряд загружаем из истории торгов ISS на шаге 3, вместе с НКД. Суммы будущих купонов и погашения линкера ISS пересчитывает каждый день по текущему номиналу — это прогноз, поэтому справочник хранит сумму платежа только с дня выплаты. Иначе линкер получал бы новую версию каждый торговый день, а первая версия переносила бы сегодняшний номинал на все прошлые даты. |

| 74 | Одна цена для длинных и коротких позиций; bid и ask можно выбрать в правило бумаги. |

Купон — по своим бумагам на дату фиксации (на счёте депо + отданные в прямое РЕПО − полученные в обратное); доход за бумаги в РЕПО НКЦ передаёт деньгами в дату выплаты, отдельной строкой. |
| 113 | Компенсационные взносы — оба варианта: не проходят по счёту фонда — не вводим; проходят — вводим по отчёту брокера или импортом, деньгами или бумагами. Денежный взнос меняет деньги и долг по сделке на одну сумму; проценты — весь денежный поток по сделке, по ночам пропорционально долгу. |
| 114 | Досрочное исполнение второй части — новая версия сделки с новой датой и суммой второй части; пересчёт с даты первой части. |
| 14 | Прогноз купонов флоатеров — плоский, по последней известной ставке индекса; только в лестнице, с пометкой «прогноз»; оценка и деньги — по объявленной сумме. |
| 115 | Прогноза номинала линкеров пока нет: суммы купонов и погашения — как объявит ISS. |
| 20 | Паи БПИФ оцениваются по биржевой цене по правилу бумаги; паи без выплат дохода. |
| 116 | Шаг 7 делаем в две части: 7.1 — РЕПО; 7.2 — прогноз купонов флоатеров и паи БПИФ. |
| 117 | Бумаги в пуле КСУ не ведём: считаем их на счёте депо, прямое РЕПО с КСУ — только деньги. Внесение и вывод из пула операциями — когда будет понятен отчёт брокера. |
